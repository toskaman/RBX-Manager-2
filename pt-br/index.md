    <div class="features-grid">
      <div class="feature-card">
        <h3>Liberação Nativa de Mutex Win32</h3>
        <p>O Roblox limita o cliente a uma única janela usando um mutex chamado <code>ROBLOX_singletonMutex</code> (e o evento <code>ROBLOX_singletonEvent</code>). O RBX Manager 2 utiliza a chamada padrão Win32 <code>DuplicateHandle</code> com <code>DUPLICATE_CLOSE_SOURCE</code> para liberar essa trava de forma limpa no nível do sistema operacional, sem modificar a memória ou o código do jogo.</p>
      </div>

      <div class="feature-card">
        <h3>Isolamento Local de Credenciais DPAPI</h3>
        <p>Seus cookies <code>.ROBLOSECURITY</code> e senhas nunca saem do seu computador. Todas as credenciais salvas são criptografadas com a API de Proteção de Dados do Windows (DPAPI) da Microsoft e senha mestra opcional. Zero telemetria externa ou armazenamento na nuvem.</p>
      </div>

      <div class="feature-card">
        <h3>Verificações Independentes de Segurança</h3>
